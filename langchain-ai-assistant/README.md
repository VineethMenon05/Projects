# 🤖 LangChain-Based AI Assistant

## 📌 Overview

This project is an AI-powered assistant built using **LangChain** and **Google Generative AI (Gemini)**.
It enables users to interact with an intelligent chatbot capable of understanding context, maintaining conversation flow, and generating human-like responses.

The application uses a simple web interface powered by **Gradio**, making it easy to test and interact with the AI assistant.

---

## 🎯 Features

* 💬 Conversational AI with context awareness
* 🧠 Powered by LangChain framework
* 🔗 Integration with Google Gemini API
* 🌐 Interactive UI using Gradio
* ⚡ Real-time response generation
* 🧾 Custom system prompt support

---

## 🛠 Tech Stack

* **Language:** Python
* **Framework:** LangChain
* **LLM:** Google Generative AI (Gemini)
* **Frontend/UI:** Gradio
* **Environment Management:** python-dotenv

## ▶️ How to Run

### 1. Clone the repository

```
git clone https://github.com/VineethMenon05/Projects.git
cd langchain-ai-assistant
```

### 2. Install dependencies

```
pip install -r requirements.txt
```

### 3. Setup environment variables

Create a `.env` file and add your API key:

```
GEMINI_API_KEY=your_api_key_here
```

### 4. Run the application

```
python main.py
```
