# 🎯 Facial Recognition & Detection System

## 📌 Overview

This project is a **real-time facial recognition and detection system** built using **Python and OpenCV**.
It detects human faces from live video streams, recognizes known individuals, and supports image capture for dataset creation.

The system can be used in applications like **attendance systems, surveillance, and identity verification**.

---

## 🚀 Features

* 🎥 Real-time face detection using webcam
* 🧠 Face recognition using trained models
* 📸 Image capture for dataset creation
* ⚡ Fast and efficient detection using OpenCV
* 🧾 Supports multiple face recognition workflows

---

## 🛠 Tech Stack

* **Language:** Python
* **Computer Vision:** OpenCV
* **Libraries:** NumPy, face-recognition
* **Tools:** VS Code

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/VineethMenon05/Projects.git
cd facial-recognition-system
```

### 2. Install dependencies

```bash
pip install opencv-python numpy face-recognition
```

### 3. Run detection

```bash
python real-time-detection.py
```

### 4. Capture images

```bash
python capture-image.py
```

## 📸 Working
